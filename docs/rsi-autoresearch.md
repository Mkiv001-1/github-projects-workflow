# RSI / autoresearch loop — канон для всех репо C:\git

Источник: вебинар Н. Рвачёва «Как я научил своих AI-агентов улучшать себя
каждый день» (Lecture Club, 2026) + Karpathy `autoresearch` (2026-03) +
Darwin Gödel Machine (Sakana AI, 2025).

Цикл: **агент делает одну правку → read-only проверка возвращает одно
число → лучше чемпиона = коммит, хуже = откат → запись в журнал →
следующая попытка**. Крутится без человека; человек задаёт направление
(program.md), рамки (scope.md) и бюджет (budget.md).

## Пять правил (hard)

1. **Одна метрика.** Одно число, которое считается само, без человека.
   Нет числа — нет цикла (только правила + журнал). Несколько метрик —
   склеить в одну или выбрать главную.
2. **Сейф.** Код проверки read-only для агента; holdout-данные агент не
   видит вообще; финальную проверку запускает человек или скрипт вне
   цикла. Реализуется `rsi_safe_gate.py` (PreToolUse) + holdout вне
   индекса git.
3. **Маленькие шаги.** Одна гипотеза → одна правка → один замер. Хуже —
   откат без сожалений. Каждая принятая правка = отдельный коммит.
4. **Журнал.** Append-only лог всех попыток (особенно неудач): что
   пробовал, зачем, число, keep/revert. Агент читает журнал ПЕРЕД
   каждой попыткой — не ходить по кругу. Это НЕ docs/failures (тот про
   классы дефектов); журнал цикла — про эксперименты.
5. **Бюджет.** Заранее: лимит попыток, стоп после N без улучшения,
   лимит времени/денег на попытку. Цена попытки считается до старта.

## Goodhart — главный риск

Агент оптимизирует число, а не задачу. Задокументированные обходы:
смена random seed как «улучшение» (autoresearch), продление себе лимита
времени (AI Scientist), чтение ответа из кода оценщика (o3), удаление
маркеров галлюцинаций (DGM). Отсюда:

- eval/ агент НЕ правит и НЕ читает изнутри — только запускает
  `run_eval` и получает stdout-число;
- holdout живёт в `autoresearch/holdout/` (gitignored) или вне репо;
  агенту чтение запрещено гейтом;
- подозрительно большой скачок метрики = повод для human review, а не
  для коммита-молчком;
- в champion-строке журнала фиксируется и число, и ЧТО изменилось —
  дрейф «метрика растёт, а суть нет» ловится на перечитывании.

## Layout репо

```
autoresearch/
  README.md        # правила цикла + как запустить (генерируется скелетом)
  program.md       # человек: цель, направление, идеи, ограничения
  scope.md         # whitelist: что агент МОЖЕТ править
  journal.md       # append-only лог попыток + строка champion
  budget.md        # лимиты и стоп-условия
  eval/
    README.md      # контракт run_eval: exit 0 + одно число в stdout
    run_eval.*     # read-only оракул (гейт защищает от правок)
  holdout/         # .gitignore: * — финальные данные, агенту нельзя
```

## Два контура

- **product**: scope = код/конфиг продукта; метрика = доменное число
  (sharpe, % пропущенного спама, accuracy на разметке).
- **harness**: scope = `.devin/skills/**`, `AGENTS.md`, `.windsurf/**`,
  hooks; метрика = характеристика работы агента (рецидив классов
  docs/failures, rework-раунды на задачу, pass-rate e2e-чеков).
  Метрика шумная → попыток мало, выводы осторожные, Goodhart-риск
  выше — keep только при явном повторяемом эффекте.

## Лайфцикл попытки (что делает скилл rsi-loop)

1. Прочитать `journal.md` (весь), `program.md`, `scope.md`, `budget.md`.
2. Стоп-условия: лимит попыток / N без улучшения / бюджет — стоп.
3. Взять следующую гипотезу из program.md (или вывести из журнала).
4. Одна правка строго внутри scope whitelist.
5. `run_eval` → число. Падение eval = revert, запись «eval broken».
6. Лучше champion → коммит (`rsi: keep <гипотеза> <old>→<new>`),
   обновить champion-строку. Иначе — `git checkout -- <files>`/revert.
7. Append в journal.md: N, дата, гипотеза, дифф-описание, число, verdict.
8. Goto 1.

Запуск: руками по запросу, или периодически через скилл `loop`
(`/loop 30m rsi-loop`), или отдельной headless-сессией агента.
Никогда — без заполненных program.md и budget.md.

## Связь с существующей инфраструктурой

- `docs/failures/INDEX.md` — классы дефектов (другое; журнал цикла —
  autoresearch/journal.md). Перед работой в scope — `check.py --diff`.
- `experiment-protocol` (trading-репо) — RSI-цикл ГЕНЕРИРУЕТ кандидатов;
  вывод «edge есть» всё равно требует пререгистрации + skeptic review.
  Цикл ≠ замена протоколу.
- `github-projects-workflow` — принятая серия правок = коммиты на ветке/
  main по обычной политике репо; вердикт цикла — комментарием в Issue.

## Минимум для старта цикла в репо

1. `program.md` заполнен человеком (цель + метрика + рамки).
2. `run_eval` реально печатает число за разумное время (<10 мин).
3. `budget.md` заполнен.
4. Гейт подключён в `.devin/hooks.v1.json`.

Без (1)-(3) скилл отказывается крутить цикл.
