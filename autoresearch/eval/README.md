# eval/ — read-only оракул (SAFE)

Контракт `run_eval`: запускается агентом, печатает в stdout ОДНО число
(последняя строка) и завершается `exit 0`. Ничего больше. Время замера
<= `budget.md:max_minutes_per_eval`.

- Агент НЕ правит и НЕ читает файлы этой директории (гейт блокирует).
- Финальная проверка — на `../holdout/` человеком или отдельным
  скриптом вне цикла. Holdout может жить и вне репо
  (например `C:si-holdout\<repo>`) — тогда положите сюда только
  указатель пути.
- Подозрительный скачок метрики -> не коммитить, показать человеку.
